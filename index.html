平庸之城隐私政策

政策版本：2026-10-19.2
适用版本：《平庸之城》1.0.2
应用包名：com.qiangu.pingyongzhicheng

《平庸之城》由千古工作室（以下简称“我们”）开发和运营。本政策说明游戏如何处理本地数据、如何响应您主动提出的反馈，以及您查看政策和管理选择的方式。隐私问题联系邮箱：1210257961@qq.com。

本版本为离线游戏，无需注册或登录，不接入广告、支付、统计分析、登录或实名认证 SDK，不设玩家信息上传后台。

本版本已停用引擎中的 AndroidID 读取，不获取 IMEI、IMSI、OAID、广告标识符或设备 MAC 地址，也不以设备标识进行跟踪。无论您选择“同意并开始”还是“不同意，仅离线游玩”，均不会启用这些采集。

声音偏好和隐私选择仅保存在应用自己的存储空间中。拒绝同意不影响本版本的基本离线游戏功能。隐私选择不代表授权未来新增的采集行为。

一、游戏运行与本地数据

1. 离线游戏内容

城市中的居民、心情、位置和互动均为虚拟游戏状态。游戏不收集现实人物的身份、情绪或位置，不要求您提供姓名、身份证号码、手机号、住址、账号密码或支付信息。本版本不提供账号、充值、社交聊天、排行榜或云存档功能。

2. 声音设置

为记住您的偏好，游戏在应用内部存储中保存背景音乐音量、背景音乐开关和音效开关。这些设置不包含设备标识，不上传服务器；您可随时在设置中修改。

3. 隐私选择

为避免每次启动重复提示，应用在本地记录政策版本、您的选择及选择时间。记录不与设备标识或平台账号关联，不上传服务器。您可在游戏设置的“隐私与政策”入口查看全文、撤回原同意并重新选择；选择仅离线游玩后仍可使用基本游戏功能。

4. 必要运行信息

为完成画面显示、声音播放、输入响应和兼容性适配，Godot 引擎及 Android 系统会在设备上使用屏幕尺寸、图形接口能力、系统版本等运行信息，并可能生成本地运行日志或缓存。我们不将其用于广告、用户画像或跨应用跟踪，游戏没有自动上传日志或分析报告的功能。本版本已取消 AndroidID 的初始化读取。

二、权限与设备标识

本版本不申请互联网、相机、麦克风、定位、通讯录、短信、电话状态或共享存储读取权限，不读取您的照片或其他应用的文件。应用内部的声音设置和隐私选择不需要共享存储权限。

游戏不读取 AndroidID、IMEI、IMSI、OAID、广告标识符或设备 MAC 地址。未选择、拒绝、同意、重新启动以及后台恢复等状态均不会开启上述设备标识读取。

您主动打开在线政策或联系邮箱时，由系统浏览器或邮件应用完成相应操作，适用该应用自身的权限和隐私政策。游戏内提供本地政策全文，阅读该全文不需要联网。

三、您主动联系时提供的信息

您通过邮箱反馈问题或提出数据权利请求时，我们会收到您的发件邮箱、邮件内容及您主动附加的材料，仅用于回复和处理该事项，不用于营销。请勿发送与事项无关的身份证件、家庭住址、密码、支付信息或他人个人信息；截图或日志含此类内容时，请先遮盖或删除。

我们仅在处理请求所需的最短期限内保留邮件；事项处理完毕且无需继续保留时会删除，法律法规另有保存要求的除外。

四、数据保存、共享与安全

声音设置和隐私选择保存在您设备的应用内部存储中，直至您修改、清除应用数据或卸载应用。本版本关闭应用自动备份，不建立玩家信息服务器，也不将这些本地记录传送至境内或境外服务器。

我们不出售个人信息，不向广告、统计或营销合作方共享游戏中的本地记录。如因您主动要求的事项确需委托他人处理必要信息，我们会说明用途、范围及保护要求，并依法履行相应义务。

我们通过减少数据处理、保留必要的本地设置、限制反馈信息用途等措施保护信息。如发生与我们处理的信息有关的安全事件，将依法采取补救措施，并按适用要求通知受影响人员和相关部门。

五、第三方服务与政策网页

1. 引擎和游戏内组件

游戏使用 Godot 引擎及 Android 系统组件提供画面、声音和本地交互。当前版本未接入第三方登录、广告、支付、统计分析或实名认证 SDK。我们已针对本游戏停用 Godot 安卓库中的 AndroidID 预读取，不以使用引擎作为收集设备标识的理由。

2. 在线隐私政策

在线政策通过 GitHub Pages 提供静态网页托管，无需注册、登录或跳转后才能阅读全文。页面不包含我们添加的统计、广告、追踪脚本、第三方字体或嵌入式媒体，也不设置用于用户画像的 Cookie。

您主动通过浏览器访问在线页面时，根据 GitHub 的说明，GitHub Pages 会出于安全目的记录和保存访问者 IP 地址，无论访问者是否登录 GitHub。网页请求还可能涉及请求时间、浏览器及基础请求信息，网络处理地点可能包含境外。相关处理请参阅 GitHub 隐私声明和 GitHub Pages 数据收集说明。此类网页访问与游戏内离线运行相互独立。您可以只阅读应用内的本地政策，无需访问网站。

3. 分发平台和邮箱

您在 TapTap 等分发平台浏览、下载或评价游戏，或使用邮件服务联系我们时，相关平台和邮件服务按自身隐私政策处理其服务所需的信息。游戏不会因此自动获得您的平台账号、实名资料或支付信息。

六、您的选择与数据管理

  • 阅读政策：首次启动时可查看全文，之后可从游戏设置中的“隐私与政策”入口再次查看。
  • 拒绝或撤回：可选择“不同意，仅离线游玩”；已同意的，也可在上述入口撤回并重新选择。拒绝不会开启设备标识读取，也不影响基本离线游戏。
  • 修改本地设置：可在设置面板调整背景音乐音量、音乐开关和音效开关。
  • 清除本地数据：可在 Android 系统的应用管理中，找到“平庸之城”，选择清除应用数据；这将重置声音设置和隐私选择。卸载应用也会移除应用本地数据。具体入口名称因设备而异。
  • 账号与反馈信息：游戏没有账号体系，因此没有游戏账号注销步骤。对于您主动发送并由我们保存的反馈信息，可通过邮箱申请查阅、复制、更正、删除、撤回同意或要求解释说明。我们仅核验完成请求所必要的信息。

我们通常在收到请求后的十五个工作日内回复，合理请求不收取费用。依法无法满足请求时，会说明理由。撤回同意不影响撤回前已经合法进行的处理；您也可依法向有权部门投诉或寻求救济。

七、未成年人保护

未成年人应在监护人指导下阅读本政策并合理安排游戏时间。当前版本不要求提供年龄、身份证件或其他用于识别未成年人身份的信息，不主动收集不满十四周岁未成年人的个人信息。

如儿童需要反馈问题，请由监护人联系并避免提供不必要的儿童个人信息。若发现未经所需监护人同意收到了相关信息，我们会依法处理，包括删除不应保留的信息。

八、政策更新

政策更新时会注明更新日期和版本。涉及个人信息处理目的、种类、方式或您权利的重大变化，会在相关处理开始前重新作出明确告知，并依法取得所需的同意。旧版本的同意不会自动授权新增的采集。应用会在需要重新选择的政策版本更新后再次提示。
