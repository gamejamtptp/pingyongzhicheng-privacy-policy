温馨提示

欢迎使用《平庸之城》。本游戏由千古工作室（以下简称“我们”）开发和运营。本政策说明当前版本在提供游戏功能、保存本地设置、接受反馈以及展示本政策时如何处理信息，以及您管理相关信息的方式。

当前游戏功能在设备本地运行，无需注册游戏账号；未接入登录、广告、支付或统计分析 SDK，也没有向我们上传玩家身份信息、设备标识或游戏操作记录的功能。音乐音量、音乐开关和音效开关保存在您的设备上。您主动通过电子邮件联系我们时，我们会收到您发送的内容和用于回复的联系信息。

本政策页面由 GitHub Pages 提供托管。浏览页面会产生网站访问请求，相关说明见第五节。请您阅读以下内容；如有疑问，可通过第十节的联系方式与我们联系。未成年人请与监护人共同阅读。

一 我们如何收集和使用您的个人信息

1 游戏运行和本地设置

当前游戏不提供账号注册、登录、用户实名认证、充值、聊天、排行榜或云存档功能，不因此要求您提交姓名、身份证号码、手机号码、密码或支付信息。游戏中的居民、心情、位置及互动属于虚拟游戏状态，不是对现实人物身份、情绪或位置的采集。

为记住您的声音偏好，游戏在应用自己的存储空间保存背景音乐音量、背景音乐开关和游戏音效开关。这些设置不包含身份标识，不上传至我们的服务器。游戏引擎及操作系统可能在设备上生成必要的运行日志或缓存；当前游戏没有自动上传日志或分析报告的功能。

2 您主动联系时提供的信息

您通过联系邮箱咨询、反馈问题或行使个人信息权利时，我们会收到您的发件邮箱、邮件内容及您自行附加的材料，仅用于回复和处理该事项。请避免发送与问题无关的身份证件、密码、支付信息或他人个人信息；截图和日志中如含有这类内容，请先遮盖或移除。

3 设备权限

当前游戏功能不调用相机、麦克风、定位、通讯录、短信、通话记录或照片读取功能，也不读取 IMEI、IMSI、OAID、广告标识符或设备 MAC 地址。本地声音设置使用应用自身的存储空间，不需要读取您的相册或其他应用文件。

功能或访问类型使用情况及目的
应用内部存储保存和读取音乐音量、音乐开关及音效开关，可通过系统应用设置清除。
相机、麦克风、位置、通讯录等敏感访问当前游戏功能不调用，不以授权这些访问作为游玩的条件。
访问本政策网页或发送邮件由您使用的浏览器或邮件应用完成网络请求，第三方服务的处理情况见第五节。

4 信息使用范围

我们仅为本政策列明的目的处理所需信息，不使用相关信息进行广告推荐或用户画像。今后增加新的个人信息处理功能时，会在实际处理前告知目的、方式、种类及保存期限，并在法律要求的情况下取得相应同意。依法无需取得同意的情形，仅在适用法律规定的范围内处理。

二 我们如何保存您的个人信息

游戏声音设置保存在您设备的应用数据目录中，供后续启动读取。您可在 Android 系统的应用管理中清除本游戏的数据，或卸载游戏以移除应用本地数据；系统备份及恢复可能受您设备或云备份服务的设置影响，我们无法远程管理这些备份。

您主动发送的邮件仅在处理请求所需的最短期限内保存；目的实现或不再需要时，我们会删除相关信息，法律法规要求继续保存的除外。如依法必须继续保存，将限制为存储及必要安全保护用途。

当前游戏不设玩家信息上传后台，也不将上述本地设置上传至境内或境外服务器。您自行访问政策网站、使用邮箱或分发平台时，服务提供者可能按照其隐私政策在其运营地区处理访问或通信数据，详情见第五节。

三 我们如何使用 Cookies 和同类技术

当前游戏不使用 Cookies、广告追踪像素或类似技术进行跨应用追踪。本政策网页不设置统计分析、广告脚本、第三方字体或嵌入式媒体。浏览器、GitHub 及您主动访问的其他服务可能依照各自政策处理网站访问数据；您可通过浏览器设置管理相关数据。

四 我们如何共享、转让、公开披露您的个人信息

我们不出售您的个人信息，也不将您主动提交的反馈内容提供给广告或营销合作方。当前游戏没有面向第三方共享玩家个人信息的接口或功能。

如因处理您要求的事项确需委托服务提供者处理必要信息，我们会明确用途、范围和保护要求，并依法履行告知及其他义务。向其他个人信息处理者提供信息、公开披露信息或处理敏感个人信息时，将按适用法律履行相应义务并在需要时取得单独同意。

发生合并、分立、解散等需要转移个人信息的情形时，我们将依法告知接收方名称和联系方式，并要求其继续履行保护义务；接收方改变原有处理目的或方式时，应依法重新取得同意。依法需要向有权机关提供信息的，仅在法定范围内提供。

五 第三方产品或服务如何获得您的个人信息

1 游戏内 SDK

当前游戏功能未接入第三方登录、广告、支付、统计分析或实名认证 SDK，因此暂无上述类型 SDK 的个人信息收集清单。游戏使用 Godot 引擎进行画面、声音及本地交互处理，不代表我们通过引擎自动收集或上传您的个人信息。

2 隐私政策网页托管

本政策通过 GitHub Pages 发布。根据 GitHub 的说明，访问 Pages 网站时，GitHub 会出于安全目的记录和保存访问者 IP 地址；相关网络请求还可能涉及浏览器和请求信息。此类网站访问数据由 GitHub 按其政策处理，可能在境外处理。请参阅 GitHub 隐私声明和 GitHub Pages 数据收集说明。

3 分发平台和邮件服务

您通过 TapTap 等平台浏览、下载或评价游戏，以及使用邮件服务发送反馈时，平台或邮件服务会处理为其服务所需的信息，适用其各自的隐私政策。当前游戏不会因此自动获得您的平台账号、实名资料或支付信息。我们对实际收到并处理的反馈信息，仍按照本政策承担保护责任。

六 我们如何保护您的个人信息

我们通过减少信息处理范围、不设置游戏内个人信息上传功能、使用应用自身的存储空间以及限制反馈信息的使用范围，降低信息泄露风险。请您妥善管理设备锁屏、系统账号和邮箱，不向他人提供密码。

如发生或可能发生与我们处理的信息有关的泄露、篡改、丢失事件，我们将依法采取补救措施，并按适用要求通知受影响人员及有关部门，说明影响、处置措施、风险降低建议和联系方式。

七 您如何管理您的个人信息

修改本地设置：您可在游戏设置面板中调整背景音乐音量，以及分别开启或关闭背景音乐和游戏音效。

清除本地数据：您可在 Android 系统设置中找到“应用—平庸之城—存储”一类入口并选择清除数据，具体名称因设备而异。此操作会重置游戏的本地设置。卸载通常也会移除应用本地数据，设备或云服务保留的备份需按其设置另行管理。

账号注销：当前游戏没有自建账号体系，因此没有游戏账号注册或注销步骤。分发平台账号应通过相应平台管理。

反馈信息及其他权利：对于您主动提供并由我们保存的信息，您可通过第十节邮箱请求查阅、复制、更正、补充、删除、撤回同意或解释说明；符合法定条件时可请求转移。我们仅核验处理请求所必要的信息，不会仅为核验而要求与请求无关的身份证明。

我们通常在收到请求后的十五个工作日内回复，合理的权利请求不收取费用。依法无法满足请求时，会说明理由和可行的处理途径。撤回同意不影响撤回前已合法开展的处理。您也可向有权监管部门投诉，或依法寻求其他救济。

八 我们如何处理未成年人的个人信息

未成年人应在监护人指导下阅读本政策并合理使用游戏。当前游戏不要求提供年龄、身份证件或其他用于识别未成年人身份的信息，不主动收集不满十四周岁未成年人的个人信息。

如不满十四周岁的未成年人需要通过邮件反馈，请由监护人联系，避免发送不必要的儿童个人信息。若我们发现未经所需监护人同意收到了相关信息，将依法及时处理，包括删除不应保留的信息。监护人可通过第十节邮箱提出查询、更正或删除请求。

九 本隐私政策如何更新

我们会在本页面公布更新并调整更新日期。涉及信息处理目的、种类、方式、接收方或您权利的重大变化时，会在相关功能提供或信息处理前依法作出清晰告知，并在需要时重新取得同意。政策更新不会作为默许新增收集行为的依据。历史版本将通过本政策发布仓库的版本记录保存。
